# Contributing to ChatGPT Completion Sound

Thanks for considering a contribution.

## Before opening an issue

- Search existing issues first.
- Use the bug-report form for reproducible problems.
- Include your browser and extension version.
- Do not paste private ChatGPT conversation content.
- Keep reports focused on one problem.

## Pull requests

Small, focused pull requests are easier to review.

1. Fork the repository and create a branch for one change.
2. Keep unrelated formatting or refactoring out of the same pull request.
3. Test the affected behavior in Chrome or Edge.
4. Update the README if installation or user-visible behavior changes.
5. Explain the problem, the change and how it was tested.

The extension should remain lightweight and should not transmit conversation content to external services.

There is no guaranteed response time. This project is maintained in spare time.
